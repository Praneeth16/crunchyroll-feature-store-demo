## Conventions

* **Numbers are measured or absent.** Every latency, metric and row count in these docs
  came out of a run and has a row in [verification_log.md](verification_log.md). A model's
  own metrics are read from the registry, never restated from prose — three documents once
  carried v9 numbers while `@champion` was v10, and that is why.
* **Not met is written as not met.** [open_items.md](open_items.md) and the "what this
  demo does not do" section of the README exist so nothing has to be inferred from
  silence.
* **Preview APIs are labelled.** [feature_views.md](feature_views.md) and
  [gpu_training.md](gpu_training.md) both stand on Public Preview features that are
  enabled per workspace and are not available in every region. `make probe` reports what
  a given workspace has.
* **Generated files say so.** `serving_benchmark.md` is written by the benchmark job;
  editing it by hand will be overwritten.
